Changes: extracted only the ordered foreign_characters table into JSON and
lowercased the ASCII replacements to match Java SimpleName under Locale.ROOT.
As in Java, later rows override earlier rows; e.g. Ä maps to a, but ä to ae.
No material from the 2024 revision is used. The JSON shipped beside this notice
is the editable data corresponding to the build-time copy in the topology
JavaScript. CC BY-SA applies to the table adaptation, not the application.

CIRCLE's answer describes the CodeIgniter origin. The corresponding table
appears in CodeIgniter 3.0.3 as application/config/foreign_chars.php:
  https://github.com/bcit-ci/CodeIgniter/blob/e7f0e7aa3d48778b5ad926eda14c825f62f421eb/application/config/foreign_chars.php
It has an additional Þ/þ row that is not in CIRCLE's revision or in Nodel.
The project's MIT copyright and license notice is retained in
CodeIgniter-MIT.txt in this directory. No PHP or C# functions are incorporated.
